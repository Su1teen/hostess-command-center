# Облегчённая версия для старых планшетов (`/lite`)

Адрес: `https://<домен Command Center>/lite` (например `https://admin.hostes.online/lite`).

## Зачем

Основной Command Center (React 19, TanStack Start, Tailwind v4) требует Chrome 111+ /
Safari 16.4+. Старые Android-планшеты (браузер на базе WebKit 534–537, Chrome 30–60,
браузеры Huawei без Google-сервисов) показывают страницу без стилей, и вход не
срабатывает: JavaScript-модули там не запускаются.

`/lite` — та же система (тот же сервер на Railway, та же PostgreSQL, те же логины,
роли и правила), но страницы собирает сервер:

- обычный HTML и `<form method="post">`, после каждого действия — redirect (POST-redirect-GET);
  весь сценарий работает **даже при полностью выключенном JavaScript**;
- CSS без переменных, flex-gap, grid, oklch, `@layer`; разметка на float / inline-block / table;
- маленький скрипт на ECMAScript 3 только улучшает работу: автообновление смены, заказов и зала
  каждые 6 с, звук о новом заказе, защиту от двойного нажатия. Без JS страница обновляется
  сама раз в 20 с (`<meta refresh>`);
- деньги пишутся как «тг» (в старых шрифтах нет знака ₸), шрифт системный, без Google Fonts.

## Что есть

| Раздел          | Возможности                                                                                                                                |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Смена           | счётчики «Новые / В работе / К оплате», очередь с кнопкой следующего шага, «Оплата получена», заявки на бронь (менеджер), «Скоро прибытие» |
| Заказы          | поиск по столу, имени, телефону или номеру; фильтр по статусу; карточка заказа со статусами, оплатой, отменой и историей                   |
| Зал             | столы по зонам с цветом состояния → карточка стола: посадить (в том числе по брони), завершить визит, фолио визита, новая бронь            |
| Брони           | брони на день с переключением дней, предзаказы                                                                                             |
| WhatsApp (Даян) | диалоги, чаты «ждут сотрудника» сверху (плашка и звук на смене), переписка, «Ответить самому» / «Вернуть ИИ», «Открыть WhatsApp»           |
| + Заказ         | выбор стола → количество по меню и бирже → расчёт на сервере → «Оформить» (повтор безопасен благодаря ключу идемпотентности)               |

Пока не перенесены: гости, постоянники, афиша и акции, меню, столы и QR, аналитика, продажи, поставки. Редактор плана зала и импорт меню из файла остаются в полной версии.

## Как планшет попадает в `/lite`

В `<head>` полной версии стоит проверка на ES3 (`src/lib/legacy-redirect.ts`): браузер без
ES-модулей или без `oklch` / `color-mix` сразу уходит на `/lite`. Браузер без JavaScript
уходит туда через `<noscript><meta refresh>`. Современные браузеры ничего не замечают.
Ссылка «Полная версия» внизу (`/?full=1`) отключает переадресацию на этом устройстве
(запоминается в cookie).

На планшете XOXO достаточно открыть адрес Command Center или сразу `/lite` и добавить
страницу на главный экран или в закладки.

## Безопасность

Действия вызывают те же обработчики `/api/staff/v1` внутри процесса (`src/server/lite/handler.ts`).
Проверку заголовка `Origin`, который старые браузеры часто не присылают, здесь заменяет
CSRF-токен в каждой форме (double-submit cookie `hostess-lite-csrf`). Если `Origin` или `Referer`
всё же присланы, они должны совпадать с адресом Command Center. Сессия — та же cookie
`__Host-hostess-staff`.

## Проверки

- `bun test tests/lite.unit.test.ts` (входит в `npm run test:unit`): JS разбирается как ECMAScript 3,
  CSS проверяется на отсутствие неподдерживаемых свойств, плюс страницы, CSRF, редиректы и все действия.
- `node scripts/test-lite.mjs` (CI, нужен `TEST_DATABASE_URL`): настоящая сборка и PostgreSQL.
  Проверяется весь сценарий смены в Chromium **с выключенным JavaScript** и User-Agent Huawei
  на Android 4.4, затем автообновление с включённым JS, переадресация из полной версии
  и отрисовка в WebKit. Скриншоты сохраняются в `test-results/lite-*.png`.

## Ограничения, на которые код не влияет

- Railway отдаёт только TLS 1.2+. Штатный браузер Android 4.0–4.3 по умолчанию не умеет TLS 1.2.
  Если страница входа открывается, этот барьер уже пройден.
- Звук на старых Android включается только после нажатия «Звук: вкл» (ограничение автозапуска).
